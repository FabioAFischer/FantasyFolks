# Pintura de materiais da candidata

Ferramenta: imagegen integrada; a imagem existente do Goblin é referência visual,
não uma textura vanilla. O resultado é uma folha de materiais intermediária.
As faces finais são montadas nas coordenadas extraídas do modelo 26.3.

Prompt:

Create an original pixel-art material sheet for the existing olive-green goblin
texture shown as reference. Square image, four equal quadrants meeting at the
exact center, full bleed, no margins, no text, no objects, no figures, no UV nets,
no outlines and no lighting gradients. Each quadrant must be a uniform tileable
material with restrained Minecraft-style pixel variation on a strict 64 by 64
logical pixel grid (each quadrant 32 by 32 logical pixels, enlarged cleanly).
Top left: muted olive-green skin, palette #687537 #788342 #59652f.
Top right: worn medium brown tunic cloth, palette #69472e #785438 #573a28.
Bottom left: pale linen bandages, palette #cbbd92 #e0d1a5 #b1a47e.
Bottom right: dark brown leather for belt and boots, palette #493224 #593e2a #35281f.
Match the reference's quiet earthy colors. Hard-edged pixel art, no antialiasing,
no noise finer than the logical pixel grid, no accessories, no buckles, no bags.
